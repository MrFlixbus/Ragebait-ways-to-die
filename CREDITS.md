# Credits and asset provenance

## Original work

The RAGEBAIT WAYS TO DIE title treatment, favicon, orange temporary employee, printer creature, gym robot, escalator/shredder, cookie creatures, scenery, UI, animations and particles were created specifically for this repository using Canvas 2D, CSS and SVG. No third-party image packs, character assets or raster images are included.

All audio is original synthesized Web Audio: short square-wave interaction sounds, an ascending success arpeggio, a descending death glissando, and separate triangle-wave sequences for the menu and four scenarios. There are no sampled recordings, external music downloads or copyrighted song excerpts.

The game uses system fonts (Arial / Helvetica / Impact and fallbacks); it distributes no font files.

## Tools and dependencies

Vite, TypeScript, Vitest, ESLint, typescript-eslint and Prettier are development tools. Their upstream licenses are retained in installed package metadata. The game has no third-party production runtime dependencies. `package-lock.json` records exact packages and versions.

The brief referenced the short survival-minigame genre. No artwork, characters, scenarios, songs, sound effects, branding or UI from Dumb Ways to Die were copied.

If adding any external asset, append its filename, author, direct source URL, explicit license and any modifications here before committing it. This file describes provenance; it does not assign an open-source license to the repository owner's original game code or assets.
